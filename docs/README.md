# plan_maker

Extracted from `tools/greenhouse-plan-editor` as part of the simulace reorg (v1.11, branch `sim/plan-maker-extraction`).

## Port

Default: `PLAN_MAKER_PORT` or `PLAN_EDITOR_PORT` env, fallback 5177.

```
npm run plan-maker
```

## API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/plan-maker/symbols/bundle` | JS bundle of all registered symbols |
| GET | `/api/plan-maker/symbols/bundle/info` | Cache info: file count, size, build timestamp |
| GET | `/api/plan-maker/plans/default-home` | Default home plan (plan-editor-v2 JSON) |
| GET | `/api/plan-maker/export/default-home/plan-editor-v2` | Download default home as plan-editor-v2 |
| GET | `/api/plan-maker/export/default-home/home-3d` | Rooms + devices projection for home-3d |

## Default Home Plan Source

`v1.11_workplan/agent_pool/projects/virtual_house/plan_editor/zonio-modern-house-4plus1.plan-editor.json`

Generated by `npm run sim:house-plan` (script: `tools/sim/generate-virtual-house-plan.js`).

## Compatibility

- `npm run plan-editor` still launches `tools/greenhouse-plan-editor/server.js` unchanged.
- plan-editor-v2 JSON import/export format is preserved in plan_maker.
- Old `/api/plan-editor/*` endpoints remain accessible via the old server.
